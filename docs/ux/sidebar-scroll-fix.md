# Sidebar desktop scroll fix

Status: active fix in Inventory & Warehouse increment.

Problem: pada viewport desktop dengan tinggi terbatas, menu bagian bawah tidak terlihat karena sidebar fixed-height tidak memberi area scroll pada nav.

Solution baseline:
- sidebar tetap setinggi viewport;
- brand dan footer tetap terlihat;
- hanya area navigasi yang scroll vertikal;
- tidak menambah scrollbar kedua pada workspace;
- mobile menu tidak diubah.
